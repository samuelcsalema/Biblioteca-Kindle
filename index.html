Onde ficam seus dados?

Salvamento automático: por padrão, seus livros ficam salvos neste navegador e neste dispositivo.

Arquivo JSON: use Exportar JSON para baixar uma cópia portátil de todos os dados, incluindo capas, personagens, notas e comentários. Use Importar JSON para restaurar uma cópia; a importação substitui a biblioteca atual.

Sincronização com arquivo: no Chrome ou Edge em um contexto compatível, clique em Vincular JSON e selecione um arquivo JSON existente. Depois de autorizar, as alterações são gravadas nele automaticamente. Se o recurso não estiver disponível, exporte o JSON manualmente.

Privacidade: o site não tem login, servidor ou banco de dados remoto. As imagens são comprimidas no próprio navegador.

Dica: faça exportações de backup regularmente. Limpar os dados do navegador pode apagar a cópia local.
